# Serafín Shell

Barra + visualizador de audio (domo/pulse) para Quickshell (QML), temática angelical.
Corre con: `qs -c serafin`

## Estructura
- `quickshell/serafin/` → shell.qml, Wallpapers.qml, cava.conf
- `bin/` → serafin-wall (cambia wallpaper + recolorea), serafin-thumbs, serafin-backup
- `matugen/` → config.toml y plantillas de color
- `hypr/` → hyprland.conf
